# 兼容范围与已知限制

此页对应 GitHub 便携发行版 1.0.2。它保持 EXE 旁的用户数据和便携版系统集成行为，并非 Steam 发行包。

## 原生隐藏托盘

当前适配在 Windows 11 25H2、系统构建 26200.9974 上核验。`native/TrayModelBridge.c` 只接受 Taskbar.dll 的 CodeView GUID `63C1425A-7856-E31E-2D8C-1BCEE438EF9E`、Age 1，并检查模块架构、任务栏线程和关键接口入口。Windows 更新后即使仍名为 Windows 11 25H2，也可能失去适配。

模块签名不匹配时，在调用固定入口前返回 ERROR_NOT_SUPPORTED；托盘客户端显示“当前 Windows 版本的原生托盘接口尚未适配”。这种情况下原生托盘网格与双向排序不可用，其他组件不因此获得兼容保证。项目没有用历史注册表快照或固定图案冒充活跃图标。

支持的布局下，成员、顺序、图案、提示与动作来自 Explorer 实时模型；拖动会修改 Windows 实际托盘顺序。测试仅操作本程序自建临时图标并恢复其相对顺序，不自动操作用户第三方托盘菜单。

依据：`native/TrayModelBridge.c` 的 `VerifiedModule`、`UseOverflow`，`native/TrayModel.cs` 的 `Send`，以及 `native/TrayFixture.cs` 的 `CheckModel`。当前只有该模块签名获得适配，未声明 Windows 10、ARM64 或其他任务栏版本支持。

## 路径、硬件与交互

- 需要 Windows x64、.NET Framework 4.8，以及可写的解压目录。ZIP 应完整解压后运行。
- 使用 EXE 旁的“用户数据”；移动整个目录时仍需更新外部快捷方式和自启动入口。普通文件从外部导入会移动真实原件到桌面。
- 截图浏览目录已缩短并验证本次深目录案例；并不代表整个应用支持超过传统 Windows 限制的任意长路径。建议使用较短目录。
- GPU 温度依赖可用的 NVIDIA NVML，网络速率依赖系统接口计数器；亮度、Wi-Fi、蓝牙和声音控制取决于设备、驱动和权限。
- 程序可隐藏任务栏并占用 F12，F12 可恢复；异常退出与 Explorer 重启下不保证全部系统状态恢复。
- 未完成多机器、多显示器/全部 DPI、Windows 登录冷启动、所有第三方应用、全部硬件控制以及照片应用内物理翻页验收。
- 程序未签名，也未经过全面安全审计。

## 源码中的 Steam 构建选项

源码保留独立 Steam 候选构建开关。`构建.ps1 -Steam` 要求显式输出到独立目录，使用另一套默认数据路径和系统集成策略；该路径本次没有作为 Steam 产品发布，也不属于 1.0.2 ZIP 的验证范围。不要用该开关替代普通便携构建。
