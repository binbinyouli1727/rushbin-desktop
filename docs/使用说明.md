# 使用说明

## 开始使用

把整个压缩包解压到当前用户可写的文件夹，再运行 `DeskBox.exe`。请勿直接在压缩包中运行，或放在需要管理员写入权限的目录。

默认 F1 打开组件管理，F5 切换主面板。组件管理可以开关组件、修改显示快捷键并查看快捷键总览。F4、F6、F12 的特殊操作目前不能自定义；快捷键可能被其他软件占用。

## 文件与分组

主面板和文件窗口访问同一批实际桌面文件，重命名、移动、删除会同步；主面板分组与各自排序仍独立。文件窗口主要显示普通文件和文件夹，应用入口主要在主面板。

添加桌面外的普通文件或文件夹时，会将原件移动到 Windows 实际桌面目录，原位置不再保留。这与 1.0.0 的复制行为不同。应用本体通常保持原位并创建快捷方式；同名文件自动编号，不能覆盖现有文件。文件移动、剪切、粘贴和原生右键菜单可能改变实际文件，请留意路径。

桌面的文件新增、改名或移出会同步更新入口。原生 Windows 文件和背景右键菜单包含本机注册的扩展，其实际功能取决于 Windows 与已安装软件。

“从收纳箱移除”只移除入口，但桌面同步可能重新发现仍在桌面的文件。“删除文件”会尝试把实际文件移入 Windows 回收站，并从两个窗口移除；删除快捷方式只删除快捷方式。回收站可用性依位置和系统配置而异。

## 截图晾衣架

截图复制到剪贴板后轻按 F4 挂图，长按 F4 临时置顶；Shift+F4 显示或隐藏截图架。空架默认隐藏，也可手动唤出后拖入图片。副本保存在 `用户数据/screenshot-line`。删除尝试回收本程序的副本，不删除外部原图。

底部分页圆点和鼠标滚轮均可切页。双击交给系统原生看图应用。默认应用为 Windows 照片时，通过公开 URI 入口打开，按组件清单创建有序浏览副本，排除目录中的未列出旧图。更改默认应用后按系统关联打开。

浏览副本在 `用户数据/screenshot-line/native-view`，照片中编辑副本不会回写组件原图。组件重排、增删后请从组件重新打开；已打开的照片窗口不会强制关闭或重新排序。Windows 照片各版本的翻页行为仍需实际验证。1.0.2 缩短了浏览缓存目录名，修复了本次深目录路径超限案例；尚未提供任意长路径支持，解压时仍建议使用较短目录。

## 底栏与控制中心

底栏图标支持固定、排序、切换和再次点击最小化；F6 按住时临时置顶。消息提示依赖应用发送 Shell 闪烁事件，不保证覆盖全部 Toast、托盘或应用内通知。

控制中心提供音量、亮度、Wi-Fi、蓝牙、电池、托盘和任务管理器入口。外接屏、驱动、设备权限和第三方应用可能影响功能；本次发布未执行真实断网、配对或所有设备控制测试。

控制中心的隐藏托盘直接读取 Explorer 活跃成员与顺序，使用原生图标处理单击、双击、右键、中键、自绘提示和排序。当前适配受 Taskbar.dll 精确符号签名限制，实测 Windows 11 25H2 26200.9974；其他签名显示尚未适配。这与旧版自绘托盘独立排序不同，拖动会改变 Windows 托盘实际顺序。详情见 `docs/COMPATIBILITY.md`。

底栏修复了资源管理器固定项归组、任务管理器和部分已识别启动器的窗口唤回；应用确实未响应时显示提示，不把发出请求视为操作完成。时钟增加实体联网网卡速率、可用的 NVIDIA GPU 温度，移除桌面合成帧率。

## 系统行为与数据位置

- 配置及截图：`DeskBox.exe` 同目录的 `用户数据`。退出程序后备份整个目录，同时单独备份桌面上的实际文件。可用 `--data-dir` 指定隔离目录。
- 旧版升级：1.0.0 默认使用 `%LOCALAPPDATA%\DeskBox`。新版不会自动搬迁旧数据。先退出旧版，备份旧目录，再将其完整复制为新版旁的 `用户数据`；若新版已有数据，先分别备份并人工核对，勿直接合并覆盖。旧配置中的绝对路径与快捷方式需要逐项核对，确认完整后再考虑清理旧目录。
- 移动整个程序目录时一并移动 `用户数据`；开机自启、开始菜单及其他外部快捷方式的绝对路径需同步更新。
- 系统任务栏：可隐藏，F12 切换；正常退出及原生保护进程会尝试恢复。异常退出、Explorer 重启和不同 Windows 版本下仍不保证恢复成功。
- 消息提醒：可能临时更改当前用户任务栏闪烁和角标设置，记录先前值并尝试在退出时恢复。
- 剪贴板：监听图片变化以准备最近图片，F4 才将其挂到截图架。请勿把敏感图片放入共享备份。
- 托盘：原生桥接监听 Explorer 托盘事件，可能受 Windows 版本、安全软件或第三方应用影响。
- 自启：构建和解压不会添加开机自启。需要时在当前用户启动文件夹自行创建快捷方式，取消时删除快捷方式。

## 验证范围

本项目主要在 Windows 11 x64 开发。程序未签名，尚未完成全面安全审计、多机器、多屏/DPI、Windows 登录冷启动或 Windows 照片内完整物理翻页验收。

代码入口与行为来源：`DeskBox.cs` 中的 `AppPaths`、`DesktopStorage`、`Program`，以及 `native/DesktopFiles.cs`、`native/NativeFileMenu.cs`、`native/ScreenshotLine.cs`、`native/TaskbarVisibility.cs`。具体发布检查见 `docs/releases/1.0.2-validation.md`。
