# 使用说明

## 开始使用

运行 `DeskBox.exe`。默认 F1 打开组件管理，F5 切换主面板；主面板顶部可搜索或添加入口，右键可管理入口。面板以外点击可收起主面板；拖动组件边缘可调整支持缩放的窗口。

组件管理里可以开关时间、主面板、控制中心、截图架、底栏和文件窗口，修改各自的显示快捷键，并查看快捷键总览。按键被占用时请改用其他组合。F4、F6、F12 的特殊操作目前不能自定义。

## 文件与分组

主面板的分组只影响 rushbin 内部整理。添加系统桌面以外的普通文件或文件夹时，程序将其复制到系统实际桌面目录，保留原件；应用本体通常保持原位并创建快捷方式。桌面路径可能因用户重定向等而变化，不固定为某个盘符。

“从收纳箱移除”只移除入口；“删除文件”会尝试将入口指向的实际文件移入 Windows 回收站，删除快捷方式时只删除该快捷方式。请先确认菜单文字及文件路径；回收站可用性依文件位置和系统配置而异。

## 截图晾衣架

截图复制到剪贴板后轻按 F4 挂图，长按 F4 临时置顶截图架；Shift+F4 可显示或隐藏截图架。空架默认隐藏，也可以手动唤出后拖入图片。图片以副本保存在 `%LOCALAPPDATA%\DeskBox\screenshot-line`；删除时程序尝试把自己的副本移至回收站，不删除原图。图片超过当前空间时使用底部分页圆点。

## 底栏与控制中心

底栏图标可以固定、排序、打开或切换已有窗口；悬停可预览支持的窗口，F6 按住时临时置顶。未处理的 Shell 任务栏闪烁提醒会驱动图标提示；并非所有应用通知都发送该事件。

控制中心可查看或调整系统设备，并提供任务管理器入口。外接屏、驱动或系统策略可能不支持某些开关或亮度控制；第三方托盘图标的菜单与回调兼容性也可能不同。

## 系统行为与数据位置

- 数据、组件配置和截图副本：`%LOCALAPPDATA%\DeskBox`。建议在程序退出后备份该目录，并单独备份桌面上的实际文件。
- 系统任务栏：程序可隐藏它，F12 切换；正常退出时尝试恢复。若遇异常，可通过 Windows 设置或重启 Explorer 排查。
- 任务栏提醒：启用相关功能可能临时更改当前用户任务栏闪烁和角标注册表设置；程序记录先前值并在退出时尝试恢复。
- 剪贴板：程序监听剪贴板变化以准备截图，F4 才会将最近图片保存到截图架。请不要把敏感截图加入共享备份。
- 托盘：自绘托盘使用原生桥接监听 Explorer 的托盘事件，某些安全软件或 Windows 版本可能阻止或影响此功能。
- 开机自启：项目不会在构建时自动添加。需要自启时可自行在当前用户启动文件夹创建程序快捷方式；取消时删除该快捷方式即可。

## 常见问题

- 组件找不到：按 F1 查看组件管理；按 F12 检查系统任务栏；检查快捷键是否被其他软件占用。
- F5 未生效：检查组件快捷键是否被修改或占用；可以从程序托盘菜单操作。
- 通知没有提示：当前依赖应用发送 Windows Shell 闪烁事件，不保证覆盖所有 Toast、托盘或应用内消息。
- 玻璃、亮度或 Wi-Fi 不正常：效果和支持情况取决于 Windows 版本、设备和系统权限。
