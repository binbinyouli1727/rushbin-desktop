# rushbin 1.0.2

更新启动、文件与截图拖动、窗口唤回和原生托盘集成，并修复本次检查发现的深目录看图缓存错误。

## 更新内容

- 分步初始化桌面组件，减少首帧前的工作；底栏宽度按实际内容恢复，避免旧保存宽度造成右侧空白。
- 文件面板支持拖入文件夹；文件、截图、主面板和托盘拖动增加半透明跟手效果与动画让位。
- 截图保存提示、圆角和 DPI 居中改进，标题精简；原生浏览缓存缩短目录名，完整索引、哈希校验和旧缓存识别保留。
- 底栏修复资源管理器固定项归组、任务管理器及部分已识别启动器的窗口唤回，改善缩略图框和 DWM 大预览，显示实际检测到的未响应状态。
- 时钟显示实时网速、可读取的 NVIDIA GPU 温度、CPU/GPU 占用，移除桌面合成帧率；更新磨砂 D 图标。
- 控制中心直接显示 Explorer 活跃隐藏托盘，使用原生图案、回调和双向顺序；修复超尺寸原生位图导致图案空白。

## 兼容范围

原生隐藏托盘目前只适配已核验的 Taskbar.dll 签名，实测 Windows 11 25H2 26200.9974。其他模块签名会提示尚未适配，托盘网格与双向排序不可用。详情见 [兼容范围](https://github.com/binbinyouli1727/rushbin-desktop/blob/v1.0.2/docs/COMPATIBILITY.md) 或包内 COMPATIBILITY.md。

程序未签名。多机器、多屏/全部 DPI、Windows 登录冷启动、所有设备控制及照片应用内物理翻页尚未完整验收。部分应用的实际响应也取决于第三方程序。已修复本次深目录缓存案例，但不声明任意长路径支持。

## 下载与升级

下载 `rushbin-1.0.2-windows-x64.zip`，完整解压到可写的较短目录，运行 DeskBox.exe。此为 GitHub 便携版，未作为 Steam 产品发布。

从 1.0.1 升级：退出旧程序，备份整个程序与“用户数据”，再覆盖程序及随包说明，保留原“用户数据”。请勿在两个版本间同时运行。

从 1.0.0 升级：旧默认数据为 `%LOCALAPPDATA%\DeskBox`；退出并备份后，人工完整复制到新版 EXE 旁“用户数据”，核对绝对路径和快捷方式。若目标已有数据，不要直接合并覆盖。

普通文件导入会移动真实原件到桌面。默认 F1 组件管理、F5 主面板、F4 挂图/按住置顶、Shift+F4 截图架、F6 临时底栏、F12 隐藏/恢复任务栏。详情见 USAGE.md。
