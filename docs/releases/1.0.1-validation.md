检查入口：`scripts/test-release.ps1`，截图及便携路径测试源码位于 `scripts/tests`。完整回归源码随 `DeskBox.cs` 与 `native/*.cs` 提供。脚本遇到已有实例或任一检查失败会报错，使用全新输出目录避免读到旧结果。

## 不能从上述检查推出的结论

没有完成 Windows 照片内物理左右键/首尾计数、多机器、多显示器与全部 DPI、Windows 登录冷启动、真实 Wi-Fi 断连、蓝牙配对和全部设备控制验收。WPF 渲染 PNG 不能代表实时 DWM 玻璃合成效果。

程序未签名，也未经过全面安全审计。当前结论为“在本机隔离检查中未发现阻碍此次发布的问题”，不表示软件没有其他缺陷。
