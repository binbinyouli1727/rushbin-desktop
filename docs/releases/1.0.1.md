# rushbin 1.0.1

同步当前桌面版本的文件管理、原生图片浏览和便携数据目录改进。

## 更新

- 主面板与文件窗口同步实际桌面文件；新增文件监视、重命名、剪切/复制/粘贴与 Windows 原生右键菜单。
- 普通文件和文件夹从外部添加时移动到实际桌面，支持同名编号与跨盘移动；应用本体通常创建快捷方式。
- 文件窗口显示完整文件名，并保留各窗口独立分组/排序。
- 截图架滚轮分页与圆点同步；恢复系统原生照片入口，按组件清单生成有序浏览副本，排除未列出旧图并检查缓存完整性。
- 配置和截图改为 EXE 旁的 `用户数据`，方便整体备份和移动。
- 同步构建依赖、使用说明、数据忽略规则和发布检查脚本。

## 下载与升级

下载 `rushbin-1.0.1-windows-x64.zip`，完整解压到可写目录，运行 `DeskBox.exe`。程序未做数字签名，目标为 Windows x64，主要在 Windows 11 开发。

升级前退出旧版并备份。1.0.0 使用 `%LOCALAPPDATA%\DeskBox`；1.0.1 使用 EXE 旁 `用户数据`，不会自动迁移。保留已有数据时，将旧目录完整复制为新版旁的 `用户数据`，逐项核对绝对路径和快捷方式。已有新版数据时不要直接合并覆盖。详情见包内 `USAGE.md`。

注意：新版普通文件导入为移动，原位置不保留；删除实际桌面文件会同步影响两个窗口。

默认 F1 组件管理、F5 主面板、F4 挂图/按住置顶、Shift+F4 截图架、F6 临时底栏、F12 恢复/隐藏任务栏。

## 检查与限制

检查结果及其边界见 [发布验证记录](https://github.com/binbinyouli1727/rushbin-desktop/blob/main/docs/releases/1.0.1-validation.md) 或包内 `VALIDATION.md`。系统任务栏、剪贴板、通知设置及硬件控制行为见 `USAGE.md`。

多机器、多显示器/DPI、Windows 登录冷启动、全部无线/蓝牙设备和照片应用内物理翻页尚未完整验收。不能据此承诺无缺陷。源码采用 MIT；第三方名称、素材及图标保留原权利。

可使用附件 `SHA256SUMS.txt` 核对 ZIP。
