# rushbin 1.0.0

首次公开版本，包含以下桌面组件：

- rushbin 主面板：搜索、分组、文件与应用入口及排序。
- rushbin·文件：拖入拖出、文件名、图片缩略图与回收站删除。
- 底栏：应用固定与排序、运行状态、窗口预览和消息提醒。
- 控制中心：Wi-Fi、蓝牙、音量、亮度、电池、系统托盘与任务管理器入口。
- 状态挂件：时间和可用的系统读数。
- 截图晾衣架：轻按 F4 挂图、按住置顶、图片拖入与分页。
- 组件管理：各组件开关、显示快捷键和玻璃设置。

## 下载与运行

下载附件 `rushbin-1.0.0-windows-x64.zip`，解压后运行 `DeskBox.exe`。`Source code` 附件用于开发，需要自行构建。

面向 64 位 Windows，主要在 Windows 11 开发环境验证。请保留压缩包中的使用说明。程序未做数字签名。

默认 F1 打开组件管理，F5 切换主面板，Shift+F4 切换截图架，F6 按住临时显示底栏，F12 隐藏或恢复 Windows 任务栏。

## 使用前了解

程序会使用剪贴板、托盘和窗口等 Windows API；可隐藏任务栏，消息提醒可能临时调整任务栏闪烁/角标设置。退出时尝试恢复相关系统状态。

配置及截图副本位于 `%LOCALAPPDATA%\DeskBox`。添加桌面外普通文件时会复制到系统桌面；删除实际文件与移除面板入口是不同操作。

硬件控制、第三方托盘、窗口预览与通知效果受系统及应用支持情况影响；FPS 暂无实际测量，F4、F6、F12 的特殊行为暂不能自定义。尚未完成多机器、所有多屏/DPI 场景及完整冷启动验证。
